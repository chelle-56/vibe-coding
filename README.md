# 賈克・大地電影世界

純 HTML、CSS、JavaScript 製作的多頁式靜態網站。

## 本機開啟
直接雙擊 `index.html`。若瀏覽器限制部分嵌入內容，可使用 VS Code 的 Live Server。

## GitHub Pages 部署
1. 在 GitHub 建立新的公開 Repository。
2. 將本資料夾內所有檔案上傳到 Repository 根目錄。
3. 進入 `Settings` → `Pages`。
4. `Build and deployment` 選擇 `Deploy from a branch`。
5. Branch 選 `main`，資料夾選 `/ (root)`，按下 `Save`。
6. 等待約 1–5 分鐘，GitHub 會顯示網站網址。
